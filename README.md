# Ecossistema Maker e Fígital — Inatel Startups

Seção interativa do Ecossistema Maker e Fígital do Inatel Startups desenvolvida para integração via `<iframe>` ou inclusão direta no portal oficial.

## ✨ Características
- **Layout Inline Expandable (In-Place Drawer):** Sem modais flutuantes. Os detalhes dos espaços expandem suavemente abaixo dos cards.
- **Imunidade a Cabeçalhos Fixos:** Elimina qualquer colisão visual com os menus superiores fixos do Inatel.
- **Auto-resize Inteligente:** Notifica a página hospedeira via `postMessage` (`inatel-maker-resize`) usando `ResizeObserver` para ajustar a altura sem barras de rolagem internas.
- **Design System Inatel:** Tipografia *Plus Jakarta Sans*, fundo azul marinho profundo (`#060B1E`), acabamentos em laranja elétrico (`#FF5E00`) e suporte a dispositivos móveis.
